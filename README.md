# Satzglieder-Trainer

Interaktiver Trainer für Satzglieder (Klasse 6). Schwester-App zum [Adverbien-Trainer](https://adverbien-trainer.vercel.app).

## Start

```bash
npm install
npm run dev
```

Production build: `npm run build` · preview: `npm run preview`

## Bereiche

1. **Grundlagen kennenlernen** (Module 1–10, ohne Punkte)
2. **Trainieren** — Grenzen, Verschiebeprobe, Prädikat, Subjekt, Objekte, Adverbiale, Ganzsatzanalyse, Gemischtes Training

Fortschritt wird lokal in `localStorage` gespeichert.
